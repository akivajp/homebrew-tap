# akivajp/tap

Homebrew formulae for [rigtop](https://github.com/akivajp/rigtop), a system monitor for workstations, laptops and NAS (terminal UI and native GUI, many hosts over SSH).

```sh
brew install akivajp/tap/rigtop
```

macOS on Apple Silicon and Linux (x86_64, aarch64). Update with `brew upgrade rigtop`.

The formula is maintained in the rigtop repository ([`packaging/homebrew/rigtop.rb`](https://github.com/akivajp/rigtop/blob/main/packaging/homebrew/rigtop.rb)) and copied here for each release.
